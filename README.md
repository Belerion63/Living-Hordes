# Living Hordes

Documentation for **Living Hordes**, a Project Zomboid mod that replaces the vanilla
zombie population system with a map-wide simulation: hordes that roam, migrate, merge,
split and settle whether or not anyone is watching.

The site is bilingual (FR / EN) and explains each system in turn, with diagrams.

- Documentation: https://belerion63.github.io/Living-Hordes/
- Steam Workshop: https://steamcommunity.com/sharedfiles/filedetails/?id=3691686404

Plain HTML, no build step. Every page loads `assets/site.css` and `assets/site.js`.
